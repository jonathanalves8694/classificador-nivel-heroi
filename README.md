# ⚔️ Desafio Classificador de Nível de Herói

Projeto desenvolvido para o desafio de lógica de programação.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Funcionalidades

O usuário informa:
- Nome do herói
- Quantidade de XP

O sistema classifica o herói conforme a tabela:

- Menor que 1000 XP → Ferro
- 1001 a 2000 XP → Bronze
- 2001 a 5000 XP → Prata
- 5001 a 7000 XP → Ouro
- 7001 a 8000 XP → Platina
- 8001 a 9000 XP → Ascendente
- 9001 a 10000 XP → Imortal
- 10001 ou mais XP → Radiante

## Como executar

Abra o arquivo `index.html` no navegador.
